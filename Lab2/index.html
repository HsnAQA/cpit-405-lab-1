Lab 2: HTML

Course website: https://cpit405.gitlab.io

HTML gives a web page its structure. Every page has a head part with information about the page and a body part with the content the user sees.

In this lab I practice the most common HTML tags: headings, paragraphs, lists, tables, and forms, and then I publish the page on GitHub Pages.

The head element holds data about the page, such as its title.

The body element holds everything that is displayed in the browser.

The area of a square with side x is x2.

Water is written as H2O.

A span is an inline element used to format part of a text.
