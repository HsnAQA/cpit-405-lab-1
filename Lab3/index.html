Task 2: Which color does each span get?

The given code (try it here: move the mouse over the words):

Every one can success.

One machine can do the work of fifty ordinary men. No machine can do the work of one extraordinary man.

My answer:

color color when mouse over
span.myclass1 pink blue
span.myclass2 pink pink
span.myclass3 orange orange
span.myclass4 red red

Why

  • myclass1: #header span (one ID + one element) is stronger than span, so it is pink. On hover, #header span:first-child:hover (one ID + two pseudo-classes + one element) is the strongest rule, so it turns blue.
  • myclass2: only #header span and span match, so it is pink. No hover rule matches it.
  • myclass3: it is the last child of #header. #header *:last-child (one ID + one pseudo-class) beats #header span (one ID + one element), so it is orange.
  • myclass4: it is not inside #header. p > span (two elements) beats span (one element), so it is red.
